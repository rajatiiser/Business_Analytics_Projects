# Business Analytics Projects

## Overview

This repository contains a collection of academic projects completed as part of coursework in Business Analytics, Data Mining, and Machine Learning. The projects focus on predictive modeling, ensemble learning techniques, and association rule mining for extracting meaningful insights from data.

Each project is organized in a separate folder and includes the implementation notebook along with project-specific documentation.

---

## Projects

### 1. Parallel Ensemble Learning

This project explores parallel ensemble learning techniques for classification tasks. Multiple base learners are trained independently and combined to improve predictive performance and model robustness.

**Key Concepts**

* Bagging
* Random Forest
* Voting Classifier
* Ensemble Evaluation

---

### 2. Sequential Ensemble Learning

This project investigates sequential ensemble learning methods where models are trained iteratively to improve upon the errors of previous learners.

**Key Concepts**

* Boosting
* AdaBoost
* Gradient Boosting
* Model Comparison

---

### 3. Market Basket Analysis

This project applies the Apriori algorithm to a synthetic transactional dataset of stationery purchases to discover frequent itemsets and association rules.

**Key Concepts**

* Association Rule Mining
* Apriori Algorithm
* Support
* Confidence
* Lift
* Market Basket Analysis
